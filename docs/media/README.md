## 终盘刚度曲线：ACP 起作用了吗

![终盘刚度曲线](sim_flip_v2ft_stiffness.png)

一句话：**接触一发生就沿接触方向变软、正交方向保持刚性，靠这个把方块翻过去。**

先认三个量：`tip` = 末端工具点，`tilt` = 方块倾角（0° 立着，≈90° 翻倒），`û` = 软轴方向（接触方向）。

按四联图从上往下对时间：

1. **接触力**：前段 `|f|`≈0（空中接近），中段出现尖峰 → 这段才是真正接触。
2. **合规偏移**：接触段 `|x_virt − x_ref|` 才明显抬起 → 有力时虚拟目标沿力方向退让。
3. **刚度对照（核心）**：`k_hard` 是水平参照线（正交一直硬），`k_soft` 在其之下并随力变化；接触段有效刚度 `|f|/|Δ|` 更低 → **只有接触那一根轴变软**。
4. **软轴 + 倾角**：`û` 在接触段随接触转向（软的方向在动，不是各向同性一起软）；`tilt` 从 0° 升到约 90° → 翻转完成。

判定看四条：接触段 `|f|` > 0、`k_soft` < `k_hard`、`û` 非零且随接触变化、max `tilt` ≥ 55°（本录屏约 90°）。本次录制四条全部满足。
